# Changelog

## 1.0.0

- Portable Windows launcher with automatic Steam-library discovery.
- Install & Play and Remove mod.
- Inventory weapon estimates using current loadout boosts.
- Quick, charged, critical, and full-health lines.
- Verified-build checks, file backups, and removal ownership checks.
- Startup retries while the game initializes its object table.
- Correct installed status while waiting for the damage worker.
